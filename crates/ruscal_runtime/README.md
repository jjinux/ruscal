# ruscal_runtime

The library every Rust program generated by
[Ruscal](https://crates.io/crates/ruscal), a Turbo Pascal to Rust
transpiler, depends on: Pascal strings, sets and files in Turbo Pascal's
byte layout, `Write`/`Read`, runtime errors with Turbo Pascal's messages,
and the `Crt`, `Dos` and `Graph` units (the features `crt`, `dos` and
`graph`).

A generated project depends on the version of `ruscal_runtime` that
matches the `ruscal` that translated it. See
<https://github.com/jjinux/ruscal>.
